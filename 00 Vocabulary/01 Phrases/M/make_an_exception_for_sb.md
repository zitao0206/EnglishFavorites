### make an exception for sb

**Desp**
phr. To allow someone not to follow a rule that others must follow.
为某人破例

**Usages**
- make an exception for a friend 为朋友破例
- make an exception for special cases 为特殊情况破例
- no exceptions made for anyone 对谁都不破例

**Examples**
1. The teacher made an exception for the sick student. 老师为生病的学生破例了。
2. We rarely make an exception for anyone, but you're special. 我们很少为任何人破例，但你是个例外。
3. The manager made an exception for her request. 经理对她的请求破了例。
