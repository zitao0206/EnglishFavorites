### regression
[rɪˈɡreʃn]

**Desp**
n. a return to a former or less developed state; a statistical method.
倒退，退步；回归分析

**Usages**
- linear regression 线性回归
- regression analysis 回归分析
- a regression to past habits 退回到旧习惯

**Examples**
1. We used linear regression to model the data. 我们用线性回归对数据建模。
2. The team's performance showed a regression last season. 上赛季球队表现出现退步。
3. Regression analysis helps identify relationships between variables. 回归分析有助于找出变量之间的关系。
