### underlying
[ˌʌndəˈlaɪɪŋ]

**Desp**
adj. basic, fundamental, but not obvious at first.
根本的，潜在的，深层的

**Usages**
- underlying logic 底层逻辑
- underlying code 底层代码

**Examples**
1. The underlying logic of this system is quite simple. 这个系统的底层逻辑相当简单。
2. We need to find the underlying cause of the problem. 我们需要找到问题的根本原因。
