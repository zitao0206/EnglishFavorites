### compatible
[kəmˈpætəbl]

**Desp**
adj. Able to exist or occur together without conflict; (of machines, software) able to be used together.
兼容的，能共存的

**Usages**
- compatible with sth 与某物兼容
- backward compatible 向后兼容
- highly compatible 高度兼容

**Examples**
1. This software is compatible with both Windows and Mac. 该软件兼容 Windows 和 Mac。
2. They are very compatible — they share the same values. 他们非常合得来——拥有相同的价值观。
3. Make sure the new hardware is compatible with our system. 确保新硬件与我们的系统兼容。
4. It is not easy to be compatible with others.
