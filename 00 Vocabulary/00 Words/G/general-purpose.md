### general-purpose
[ˌdʒenərəl ˈpɜːrpəs]

**Desp**
adj. suitable for a wide range of uses or tasks; not specialized.
多用途的，多功能的，通用的

**Extension**
同义词：versatile, multipurpose, all-purpose
反义词：specialized, dedicated

**Usages**
- a general-purpose tool 通用工具
- general-purpose language 通用编程语言
- general-purpose cleaner 多功能清洁剂

**Examples**
1. Python is a general-purpose programming language. Python 是一种通用编程语言。
2. This general-purpose cleaner works on almost any surface. 这种多功能清洁剂几乎适用于任何表面。
3. A general-purpose computer can handle many different tasks. 通用计算机能处理多种不同任务。
